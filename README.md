# 輔科舞告賀 AxcellenT｜工業風 PWA v1.0

這是一個獨立的新 PWA 網站版本。

## 功能
- 工業風響應式網站
- 真實輔具作品 PROJECT WALL
- AxcellenT 官方網站與 YouTube 入口
- 可安裝至 Android、iPhone/iPad 與支援 PWA 的桌面瀏覽器
- standalone 獨立視窗
- Service Worker 基本離線支援
- 新版本提示
- AxcellenT 專用 App 圖示

## GitHub Pages
建立新的 Repository 後，把 ZIP 解壓縮後的檔案直接上傳到 Repository 最外層。
請勿再多包一層資料夾。
接著到 Settings → Pages → Deploy from a branch → main → /(root) → Save。
